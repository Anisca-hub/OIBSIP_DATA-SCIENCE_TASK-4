📌 TASK 4: SPAM EMAIL DETECTION
📖 Overview
This project implements a machine learning-based spam detection system using Natural Language Processing (NLP) techniques.
🎯 Objective
To classify messages as:
•	Spam
•	Not Spam (Ham)
based on textual content.
📊 Dataset
•	Source: UCI SMS Spam Collection Dataset
•	Feature: Message Text
•	Target: Spam / Ham Label
🛠️ Methodology
•	Text preprocessing and cleaning
•	Feature extraction using TF-IDF
•	Model training using Naive Bayes
•	Probability-based prediction
•	Interpretability using influential words
🤖 Algorithm Used
•	Multinomial Naive Bayes
📈 Evaluation Metrics
•	Accuracy Score
•	Confusion Matrix
✅ Outcome
The system accurately detects spam messages and provides prediction confidence with explainable results.
